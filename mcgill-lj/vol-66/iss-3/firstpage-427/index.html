Advanced Citation Settings

Link Whole Cite links the complete citation to the article.

Link Pinpoint links only the page or note pinpoint. No link copies plain text.

When this is on, selecting article text automatically copies the current citation format to your clipboard.

It only runs for pinpoint or quote modes, not Base.

How it works: when selected article text includes a footnote reference, Copy Cite can add a Notes block with the matching note text.

Example: selecting text ending in 12 can copy the quote, then Notes, then note 12.

If you select note text directly, that note is not copied a second time.

When this is on, copied quotes leave out footnote callout numbers like 12.

This also overrides Copy notes if note markers selected, so the copied quote stays clean.
